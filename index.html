How to Connect Your Own Firebase Cloud (Free)

When you connect your own Firebase project, every photo you upload from your phone is saved permanently in the cloud and appears immediately on every customer's phone.

  1. Go to console.firebase.google.com and click Create a project (name it CarFashionHub).
  2. In the left menu, open Build → Firestore Database, click Create database, and start in Test Mode.
  3. Open Build → Storage, click Get started, and start in Test Mode (for product photos).
  4. Open Build → Authentication → Sign-in method and enable Anonymous login.
  5. Click the Gear icon (Project Settings) → Your apps → Web (</>), copy the firebaseConfig object, and paste it inside index.html where marked CUSTOM_FIREBASE_CONFIG.
const CUSTOM_FIREBASE_CONFIG = {
  apiKey: "AIzaSy...",
  authDomain: "carfashionhub.firebaseapp.com",
  projectId: "carfashionhub",
  storageBucket: "carfashionhub.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abcdef"
};
